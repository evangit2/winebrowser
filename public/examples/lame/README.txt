LAME 3.100: original LGPL-2.0-or-later Windows i386 WAV/PCM encoder.
Run lame.exe --silent --noreplaygain -b 128 stereo.wav output.mp3
Full unmodified upstream source, license, build recipe and configuration are in source.zip.
Optional MP3 decoder and libsndfile are not built. No game binaries are included.
