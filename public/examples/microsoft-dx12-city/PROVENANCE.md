# Microsoft D3D12Bundles city

MIT, Microsoft DirectX-Graphics-Samples revision
`be8195fc324c97c6550b710ace15e18b560c07c8`, directory
`Samples/Desktop/D3D12Bundles/src`.

Native Windows x86 build of the unchanged C++ sample. Original OCC city mesh and
BC1 texture are in `occcity.bin`; original HLSL is compiled to SM5 DXBC using the
shipped browser shader compiler. MinGW compatibility adapts SDK/WRL/header and
preprocessor conventions. Upstream scalar DirectXMath is selected; PIX profiling
is disabled. No application, scene or shader logic is replaced. This is a source
build, not a repackaged upstream release executable.

`source.zip` includes hash-pinned C++, headers, assets, HLSL, DirectXMath,
compatibility headers, generated bytecode, MIT licenses and a native `build.sh`.
With the recorded toolchain it reproduces the EXE SHA-256
`3bd477ccddbe9a50aa07db1b7408d901188a2d90391b3cde135f1ab0084ba524`.
`build.json` records the native command and compiler version.

WASD moves, arrows turn, Escape resets, and window close exits. Upload
`D3D12City-x86.zip`, or the EXE with `occcity.bin` and the three `.cso` files.
WineBrowser supplies the tested Windows DLL closure. General DLL and DX12
compatibility remain bounded to the documented x86 runtime.
